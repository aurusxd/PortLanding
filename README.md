# Lumen Render — сайт студии 3D-визуализации

Многоблочный лендинг вымышленной студии фотореалистичных 3D-визуализаций интерьеров.
Тёмная минималистичная тема, крупная типографика, анимации при скролле, калькулятор стоимости
и форма заявки с загрузкой плана — заявки приходят в Telegram.

> Студия, отзывы, клиенты и контакты вымышлены. Все изображения — рендеры, сгенерированные нейросетью.

## Стек

- **SvelteKit 3** (Svelte 5, runes) + **TypeScript**
- **Tailwind CSS 4**
- **@sveltejs/enhanced-img** — AVIF/WebP, адаптивные `srcset`, lazy-load
- **Lenis** — плавный скролл; анимации — CSS + Svelte transitions (только `transform`/`opacity`)
- Шрифты **Unbounded** (заголовки) и **Inter** (текст), self-hosted через Fontsource
- Деплой: **Vercel** (`@sveltejs/adapter-vercel`)

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
```

```bash
cp .env.example .env
```

Заполните `.env` (см. ниже), затем:

```bash
npm run dev
```

Сайт откроется на http://localhost:5173. Без переменных Telegram форма покажет пользователю
«Форма временно не настроена» — остальное работает.

Проверка типов и продакшен-сборка:

```bash
npm run check
```

```bash
npm run build
```

```bash
npm run preview
```

> На Windows адаптер Vercel не может создать симлинки без режима разработчика, поэтому при локальной
> сборке на Windows используется «пустой» адаптер (см. `vite.config.ts`). На Vercel всегда собирается
> настоящий — ничего настраивать не нужно.

## Переменные окружения

| Переменная | Что это |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | ID чата, куда бот шлёт заявки |

Переменные объявлены в `src/env.ts` и читаются только на сервере (`$app/env/private`) — в браузер не попадают.

### Как получить токен и chat id

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите токен.
2. **Заявки себе в личку:** напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет `"chat":{"id":123456789,...}`.
3. **Заявки в группу:** добавьте бота в группу, напишите там сообщение и так же посмотрите `getUpdates` —
   id группы начинается с `-100`.

## Деплой на Vercel

1. Залейте проект в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий.
   Vercel сам определит SvelteKit — настройки сборки менять не нужно.
3. **Settings → Environment Variables** — добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
   (для окружения Production) → **Redeploy**.
4. Отправьте тестовую заявку с сайта — она должна прийти в Telegram.

### Домен .ru

1. Купите домен у регистратора (Reg.ru, RU-CENTER, Beget и т. п.).
2. В Vercel: **Project → Settings → Domains → Add** → введите домен (например `lumenrender.ru`)
   и добавьте `www`-вариант с редиректом.
3. У регистратора в DNS пропишите записи, которые покажет Vercel. Обычно это:
   - `A` для `@` → `76.76.21.21`
   - `CNAME` для `www` → `cname.vercel-dns.com`
4. Подождите обновления DNS (от нескольких минут до суток). HTTPS-сертификат Vercel выпустит автоматически.
5. **Обязательно** поменяйте `SITE_URL` в `src/lib/config.ts` на свой домен и задеплойте снова —
   от него строятся canonical, OG-ссылки, sitemap и robots. Там же — телефон, почта, Telegram и адрес.

## Как устроены заявки

`POST /api/lead` (`src/routes/api/lead/+server.ts`) принимает `multipart/form-data`:

- проверяет имя и телефон (`+7` и 10 цифр), длину комментария;
- файл — до 4 МБ (лимит тела запроса на Vercel 4,5 МБ), форматы PDF, JPG, PNG, WEBP, DWG, DXF, ZIP;
- для калькулятора **пересчитывает цену на сервере** (`src/lib/pricing.ts`) и не доверяет числу из браузера;
- антиспам: скрытое поле-ловушка, минимальное время заполнения формы, не больше 5 заявок за 10 минут с одного IP;
- отправляет в Telegram сообщение (`sendMessage`, HTML) и, если есть, файл (`sendDocument`).

Расценки калькулятора меняются в `src/lib/pricing.ts`, тексты блоков — в `src/lib/data.ts`.

## Структура

```
src/
  env.ts                 объявление переменных окружения
  lib/
    config.ts            домен, контакты, навигация

    assets/img/          исходные рендеры (оптимизируются при сборке)
  routes/
    +page.svelte         главная
    privacy/             политика конфиденциальности
    api/lead/            серверный эндпоинт заявок
    sitemap.xml/ robots.txt/
static/                  favicon, og.jpg, manifest
```

## Производительность

Lighthouse на продакшен-сборке (локально):

| Профиль | Performance | Accessibility | Best Practices | SEO |
| --- | --- | --- | --- | --- |
| Desktop | 99 | 100 | 100 | 100 |
| Mobile (симуляция медленного 4G) | 83 | 100 | 100 | 100 |

Что для этого сделано: адаптивные AVIF/WebP с `srcset`, lazy-load всего ниже первого экрана,
`fetchpriority="high"` для hero, CSS встроен в HTML, preload основных шрифтов,
`content-visibility: auto` для секций ниже первого экрана, анимации только на `transform`/`opacity`,
бесконечные анимации на паузе вне экрана, плавный скролл подключается после загрузки, без GSAP.

Из-за `content-visibility` высоты секций до первого показа оценочные, поэтому переходы по якорям
(меню, `/#contacts` в адресе, ссылки со страницы политики) доводятся до точной позиции —
см. `scrollToId` и `settleToHash` в `src/lib/scroll.svelte.ts`.
