# Lumen Render — сайт студии 3D-визуализации

Многоблочный лендинг вымышленной студии фотореалистичных 3D-визуализаций интерьеров.
Тёмная минималистичная тема, крупная типографика, анимации при скролле и калькулятор стоимости.
Форм на сайте нет: все CTA открывают Telegram с заранее набранным сообщением (расчёт, тариф, проект),
поэтому сайт не собирает и не обрабатывает персональные данные.

> Студия, отзывы, клиенты и контакты вымышлены. Все изображения — рендеры, сгенерированные нейросетью.

## Стек

- **SvelteKit 3** (Svelte 5, runes) + **TypeScript**
- **Tailwind CSS 4**
- **@sveltejs/enhanced-img** — AVIF/WebP, адаптивные `srcset`, lazy-load
- **Lenis** — плавный скролл; анимации — CSS + Svelte transitions (только `transform`/`opacity`)
- Шрифты **Unbounded** (заголовки) и **Inter** (текст), self-hosted через Fontsource
- Деплой: **Vercel** (`@sveltejs/adapter-vercel`), все страницы — статика, серверных функций нет

Сделал [Никита Попов](https://popov-dev.ru).

## Деплой на Vercel

1. Залейте проект в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий.
   Vercel сам определит SvelteKit — настройки сборки менять не нужно.
3. **Deploy** — переменные окружения не нужны.

### Домен .ru

1. Купите домен у регистратора (Reg.ru, RU-CENTER, Beget и т. п.).
2. В Vercel: **Project → Settings → Domains → Add** → введите домен (например `lumenrender.ru`)
   и добавьте `www`-вариант с редиректом.
3. У регистратора в DNS пропишите записи, которые покажет Vercel. Обычно это:
   - `A` для `@` → `76.76.21.21`
   - `CNAME` для `www` → `cname.vercel-dns.com`
4. Подождите обновления DNS (от нескольких минут до суток). HTTPS-сертификат Vercel выпустит автоматически.
5. **Обязательно** поменяйте `SITE_URL` в `src/lib/config.ts` на свой домен и задеплойте снова —
   от него строятся canonical, OG-ссылки, sitemap и robots. Там же — телефон, почта, Telegram, адрес
   и функция `tgLink()`, которая собирает ссылки `t.me/<ник>?text=…`.

## Как устроены CTA

Заявки не собираются на сайте. Кнопки ведут в Telegram по ссылке `https://t.me/<ник>?text=<сообщение>` —
чат открывается с уже набранным текстом, а отправляет его сам посетитель:

- калькулятор — тип помещения, площадь, срочность и ориентировочная цена;
- «Выбрать тариф» — название и цена тарифа;
- «Хочу так же» в карточке проекта — название проекта;
- «Отправить план», «Написать в Telegram» — короткое приветствие.

Расценки калькулятора меняются в `src/lib/pricing.ts`, тексты блоков — в `src/lib/data.ts`.

## Структура

```
src/
  lib/
    config.ts            домен, контакты, навигация, tgLink(), автор
    data.ts              проекты, отзывы, тарифы, FAQ, этапы
    pricing.ts           формула калькулятора
    scroll.svelte.ts     плавный скролл и точные переходы по якорям
    actions/reveal.ts    появление при скролле, пауза анимаций вне экрана
    components/          секции страницы
    assets/img/          исходные рендеры (оптимизируются при сборке)
  routes/
    +page.svelte         главная
    privacy/             политика конфиденциальности
    sitemap.xml/ robots.txt/
static/                  favicon, og.jpg, manifest
```

## Производительность

Lighthouse на продакшен-сборке (локально):

| Профиль | Performance | Accessibility | Best Practices | SEO |
| --- | --- | --- | --- | --- |
| Desktop | 99 | 100 | 100 | 100 |
| Mobile (симуляция медленного 4G) | 83 | 100 | 100 | 100 |

Что для этого сделано: адаптивные AVIF/WebP с `srcset`, lazy-load всего ниже первого экрана,
`fetchpriority="high"` для hero, CSS встроен в HTML, preload основных шрифтов,
`content-visibility: auto` для секций ниже первого экрана, анимации только на `transform`/`opacity`,
бесконечные анимации на паузе вне экрана, плавный скролл подключается после загрузки, без GSAP.

Из-за `content-visibility` высоты секций до первого показа оценочные, поэтому переходы по якорям
(меню, `/#contacts` в адресе, ссылки со страницы политики) доводятся до точной позиции —
см. `scrollToId` и `settleToHash` в `src/lib/scroll.svelte.ts`.
